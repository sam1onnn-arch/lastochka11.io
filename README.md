# ЛаСТОчка11 — сайт автосервиса

Лендинг-визитка. Сыктывкар, ул. Школьная, 51.
Статический сайт: HTML + CSS + JS, без сборки и зависимостей.

## Структура

```
index.html              вся разметка
assets/css/style.css    стили
assets/js/main.js       прелоадер, анимации, форма
assets/img/
  hero-master.jpg       фото на главном экране
  work-balance.jpg      фон главы 01 «Сервис»
  work-gbc.jpg          фон главы 02 «Услуги»
  work-akpp.jpg         фон главы 03 «Процесс»
  work-keys.jpg         фон главы 04 «Отзывы»    (Unsplash)
  work-box.jpg          фон главы 05 «Контакты»  (Unsplash)
  og-cover.jpg          картинка для превью ссылки в мессенджерах
  logo-full.png         логотип с надписью — на заставке, фон прозрачный
  logo-mark.svg         знак без надписи — шапка, подвал
  favicon.svg
tools/                  вспомогательные скрипты, к сайту не относятся
dist/lastochka11.html   собранная однофайловая версия (создаётся скриптом)
```

Свои снимки: `work-gbc`, `work-akpp` — из бокса; `work-balance` — сток без
водяного знака. `work-keys` и `work-box` взяты на Unsplash: лицензия
разрешает коммерческое использование, атрибуция не требуется.

Файл `istockphoto-1554627149-2048x2048.jpg` **не используется** — это бесплатное
превью с iStock с водяным знаком. Убирать знак нельзя: он защищает чужое
лицензируемое фото. Либо покупать лицензию, либо заменить.

Исходники фото (`гбц.png`, `АКПП.png`, `closeup-...tyre-balancing...jpg`)
лежат рядом — они не используются страницей, но пригодятся, если
понадобится перекадрировать. Можно удалить.

### Фирменный знак

`assets/img/logo-mark.svg` — ласточка в ободе колеса, хвост уходит спицами диска.
Вектор, 2,6 КБ, стоит в шапке, подвале и на прелоадере.

В разметке знак объявлен **один раз** — блоком `<svg class="sprite">` в начале
`<body>`, а в трёх местах подставляется через `<use href="#logoMark">`. Так путь
не дублируется, и поправить рисунок можно в одном месте.

Цвет знак берёт из CSS (`fill="currentColor"`), поэтому отдельных файлов под
тёмный и светлый фон не нужно — он красится тем же цветом, что и текст рядом.

Исключение — `favicon.svg`: во вкладке стили страницы не действуют, там цвета
прописаны явно. Если поменяете знак, favicon придётся обновить отдельно.

Знак получен обводкой растрового исходника — скрипты `tools\trace-sketch.ps1`
и подготовка маски лежат рядом. Важная деталь: перед обводкой растр **размывается**,
и только потом режется порогом. Без этого обводка повторяет рваный край JPEG,
и на кривых видна мелкая волна.

### Акцентный цвет

На чёрно-белой странице есть ровно один цвет — янтарный `--accent` — и стоит он
только там, где от человека ждут действия: «Записаться» в шапке и на главном
экране, «Отправить заявку», «Позвонить» в панели быстрой связи.

Это не украшение, а указатель. Стоит раскрасить им что-то ещё — заголовок,
номер главы, цену — и цвет перестанет означать «нажми сюда», а сдержанность,
которая отличает сайт от конкурентов, пропадёт.

Зелёный у индикатора «открыто» — отдельная роль (состояние, а не действие),
поэтому цвета разные намеренно.

### Как поменять фон главы

Кадры привязаны в конце `assets/css/style.css`:

```css
#about   { --chapter-img:url('../img/work-balance.jpg'); --band-dim:1.3 }
#services{ --chapter-img:url('../img/work-gbc.jpg');     --band-dim:.92 }
#process { --chapter-img:url('../img/work-akpp.jpg');    --band-dim:.6 }
#reviews { --chapter-img:url('../img/work-keys.jpg');    --band-dim:.82; --band-pos:56% }
#contact { --chapter-img:url('../img/work-box.jpg');     --band-dim:1.02; --band-pos:52% }
```

Две ручки на каждую главу:

- `--band-dim` — яркость кадра. Снимки пришли с разной экспозицией, поэтому
  тёмный осветляется (1.3), светлый притемняется (0.6). Подбирайте так, чтобы
  подписи главы оставались читаемыми.
- `--band-pos` — что видно в полосе по вертикали (по умолчанию 42 %).
  Нужно для вертикальных кадров: у `work-keys` ладонь с ключом ушла бы
  за край, поэтому 56 %.

Пути пишутся **относительно CSS-файла**, а не HTML — `url()` внутри
CSS-переменной резолвится от места объявления.

## Однофайловая версия и публикация

Для отправки ссылкой или загрузки одним файлом собирается версия, в которую
стили, скрипт и все фотографии зашиты внутрь:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build-artifact.ps1
```

Результат — `dist\lastochka11.html`, около 1,7 МБ, открывается сам по себе,
без сервера и папки `assets`. Именно его публикуют как артефакт; `index.html`
для этого не годится — в нём пути к картинкам относительные.

Опубликованная версия:
<https://claude.ai/code/artifact/7e378a31-a020-47b2-a36a-d51008d6d689>

Второй скрипт, `tools\optimize-image.ps1`, ужимает и масштабирует снимки перед
тем, как класть их в `assets/img` — фотографии с телефона весят по 10 МБ,
на сайте им столько не нужно.

## Как открыть

Дважды кликнуть `index.html` — откроется в браузере.
Для проверки как на настоящем сервере (нужен, если добавите шрифты локально):

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1
```

### График работы — правится в трёх местах

Расходятся незаметно, поэтому меняйте все три сразу:

1. `index.html`, секция «Контакты» — то, что читает человек
2. `index.html`, `<head>`, блок `openingHoursSpecification` — то, что читают поисковики
3. `assets/js/main.js`, объект `HOURS` — по нему считается надпись
   «Открыто до 19:00» на главном экране

Надпись обновляется каждую минуту и считает по московскому времени,
а не по часам посетителя: гость из Владивостока увидит статус Сыктывкара.

### Про рейтинг в разметке

В разметку организации намеренно не добавлен `aggregateRating`. Размечать
можно только отзывы, собранные на самом сайте; выдавать чужие оценки из 2ГИС
за свои — нарушение правил Google, за которое снимают расширенные сниппеты.
Если захотите звёзды в поиске — нужен свой сбор отзывов на сайте.

### Про отзывы

В открытых источниках у ЛаСТОчка11 есть только оценка **5,0 (3 оценки)**
без опубликованных текстов. Три отзыва на странице написаны как образец —
замените их реальными из 2ГИС или Яндекс.Карт, сохранив имена и даты.

## Форма обратной связи

Сейчас форма **не отправляет** заявки — валидация и маска телефона работают,
данные уходят в `console.log`. Чтобы заявки приходили на почту:

1. Зарегистрируйтесь на [Formspree](https://formspree.io) или
   [Web3Forms](https://web3forms.com) — оба бесплатны для небольшого потока.
2. В `assets/js/main.js` найдите блок `ЗАГЛУШКА ОТПРАВКИ` и замените
   `console.log` на `fetch`-запрос по образцу в комментарии рядом.
